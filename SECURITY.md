# Security Policy

MCPCanary is a security tool, but it is an early MVP. Treat findings as review signals, not final proof.

## Reporting Vulnerabilities

Please report vulnerabilities privately by opening a GitHub security advisory when available, or by contacting the maintainer through the GitHub profile for `wayyoungboy`.

Include:

- MCPCanary version
- Operating system
- Command used
- Minimal config that reproduces the issue
- Whether the issue involves false negatives, false positives, parsing, lockfile drift, or CLI behavior

## Privacy

The CLI is local-first. v0.1 does not upload descriptors, config paths, env keys, or finding reports.
